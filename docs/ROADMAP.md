## 二、当前收尾基线总结

经过多轮深度审查与稳定性收敛，工程基础（MCP 协议与取消安全、曲库事务恢复与锁隔离、有界子进程与并发试听保护、Studio Dark UI 与双平台 CI 门禁）已稳定可用，**不再进行无针对性的大型内部架构重构**。接下来的投入全面转向真实音乐效果、Windows 真机联调与普通用户端到端产品体验。

## 三、下一阶段演进规划（Alpha → Beta / Stable）

### 优先级 A：真实音乐转谱与编曲听感提升

以有合法使用权或开放许可的真实音频与曲谱素材为中心，系统性评估并打磨实际效果：

1. **主旋律识别与剥离**：验证纯钢琴、吉他、带前奏流行歌的旋律线提取准确性。
2. **多音与和弦转谱调优**：结合外部 `basic-pitch` / `dettato` + `ffmpeg` 真实输出，补强多声部转谱后的节奏量化、八度归位与碎音清洗策略。
3. **人声伴奏混合场景**：评估混音输入下转录信噪比与编曲可演奏性之间的权衡策略。
4. **音高/节奏直观可听性**：统计从“音频导入 → 转谱 → 自动编曲 → 可直接试听/游玩”的端到端可用成功率，改善不和谐半音与密度突变问题。

### 优先级 B：Windows 10/11 真机游戏演奏验证（解除发版关键阻塞）

在具备合法环境条件的 Windows 10/11 实体机上完成完整现场验证（详见 [TEST_REPORT.md](TEST_REPORT.md) §5）：

1. **21 键映射核对**：对照《原神》风物之诗琴与镜花之琴自由演奏界面实测三行 21 键发音一致性，并将确认后的预设由 `unverified` 升级为 `verified`。
2. **长曲目时序稳定性**：检验 3–5 分钟持续演奏下的掉拍、节奏漂移与 CPU 负载影响。
3. **前景窗口护栏与急停安全性**：验证 Alt+Tab 切出窗口、`Esc` 快捷键、主动暂停/恢复的即时响应及 100% 物理松键零粘滞。

### 优先级 C：面向普通用户的产品交付打磨

优先解决真实用户的安装与上手痛点，而非继续堆积内部工程报告：

1. **开箱体验简化**：优化首次启动引导、常见错误中文提示，以及**应用内一键安装外部工具链**（`ffmpeg`、Basic Pitch、dettato）：应用负责下载 Python 运行时与隔离环境、校验哈希、安装到 `%LOCALAPPDATA%\LyraForge\tools` 并自动注入运行环境，用户无需手工配置环境变量；不把大模型打进发布 ZIP，避免安装包膨胀到 GB 级。**v1 已实现**（[PR #12](https://github.com/PariyaProject/LyraForge/pull/12)）：设置页安装卡片 + `lyraforge tools install`；后续补首次启动引导与失败重试提示。
2. **工作流连贯性**：打磨“导入 / 搜索 → 一键转谱与 A/B 选版 → Piano Roll 快速改音高/拍点 → 试听 → 演奏或导出”操作路径。
3. **Beta / Release 准备**：完成优先级 A/B 核心实测、补充稳定版签名/打包说明并经所有者确认后，再筹备首个公开预发行或正式版本。
